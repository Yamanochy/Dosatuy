# Настройка push-уведомлений (полноценных, даже при закрытом приложении)

Это отдельный, более сложный этап — потребуется один раз поработать в командной
строке на компьютере. Дальше ничего этого трогать не придётся, разошлётся всё
само через облачную функцию.

## Шаг 1. Включить платный тариф Blaze

Без этого шага облачная функция не заработает — Google требует привязать карту
к проекту для использования Cloud Functions, даже если фактически платить не
придётся (наши объёмы далеко в пределах бесплатного лимита).

1. Firebase Console → значок ⚙️ рядом с названием проекта → **Usage and billing**
2. Вкладка **Details & settings** → **Modify plan**
3. Выбери **Blaze (Pay as you go)** → привяжи карту
4. Можно (не обязательно) сразу поставить лимит бюджета — например 100 ₽/мес,
   для подстраховки: **Set budget alert**

## Шаг 2. Получить VAPID-ключ

1. Firebase Console → ⚙️ → **Project settings**
2. Вкладка **Cloud Messaging**
3. Раздел **Web configuration** → **Web Push certificates** → **Generate key pair**
4. Скопируй появившуюся длинную строку (это и есть VAPID-ключ)
5. Вставь её в файл `vapid-config.js` вместо `ВСТАВЬ_СЮДА`

## Шаг 3. Установить инструменты на компьютер

1. Если ещё нет Node.js — скачай и установи с https://nodejs.org (кнопка LTS)
2. Открой командную строку (Пуск → напиши `cmd` → Enter, или PowerShell)
3. Выполни по очереди:
   ```
   npm install -g firebase-tools
   firebase login
   ```
   Второй командой откроется браузер — войди тем же Google-аккаунтом, которым
   создавал проект Firebase.

## Шаг 4. Создать и залить облачную функцию

1. Создай где угодно новую папку, например `dosatuy-functions`
2. В командной строке перейди в неё: `cd путь\до\dosatuy-functions`
3. Выполни:
   ```
   firebase init functions
   ```
   На вопросы отвечай:
   - "Please select an option" → **Use an existing project** → выбери `dosatuy`
   - "What language..." → **JavaScript**
   - "Do you want to use ESLint?" → **No**
   - "Do you want to install dependencies now?" → **Yes**

4. После этого в папке появится подпапка `functions`. Открой в ней два файла:
   `functions/index.js` и `functions/package.json` — и полностью замени их
   содержимое на файлы `functions/index.js` и `functions/package.json`, которые
   я прислал (просто скопируй текст).

5. Снова в командной строке (находясь в папке `dosatuy-functions`):
   ```
   firebase deploy --only functions
   ```
   Дождись сообщения `✔ Deploy complete!` (может занять пару минут).

## Шаг 5. Включить уведомления в самом приложении

1. Обнови файлы приложения в GitHub-репозитории (все файлы из этого архива)
2. Открой приложение на телефоне → вкладка **Чат**
3. Нажми кнопку **«🔔 Включить уведомления»** вверху
4. Разреши уведомления, когда браузер спросит

Это нужно сделать на каждом телефоне отдельно (у каждого пользователя).

## Важно про iPhone

На iPhone push-уведомления в браузере работают только если приложение
установлено на экран «Домой» (через Safari → Поделиться → «На экран Домой»,
именно так, как мы и советовали ставить приложение) и на iOS 16.4 и новее.
Если просто открыть сайт в Safari без установки — уведомления не придут.

## Если что-то не получится

Пришли скриншот ошибки в командной строке или в консоли Firebase — разберём.
